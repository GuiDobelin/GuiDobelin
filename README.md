## 🚀 Projetos

### [Blog API — Microsserviços](https://github.com/GuiDobelin/blog)
API de blog dividida em 3 microsserviços independentes (usuários, posts e comentários) com autenticação JWT, senhas com bcrypt, controle de autoria (só o autor edita ou remove o próprio conteúdo), migrations com Sequelize e orquestração completa com Docker Compose. Inclui coleção do Postman.

`Node.js` `Express` `Sequelize` `PostgreSQL` `JWT` `Docker`

---

### [Chat em Tempo Real](https://github.com/GuiDobelin/chat)
Aplicação full-stack de chat com salas, cadastro e login. Mensagens em tempo real via WebSocket com Socket.IO autenticado por JWT, histórico salvo no MongoDB e frontend em React.

`React` `Node.js` `Express` `Socket.IO` `MongoDB` `JWT`

---

### [Animal Adoption](https://github.com/GuiDobelin/animal-adoption)
Sistema de terminal para cadastro de animais e adotantes, com relatório de cruzamento entre espécies disponíveis e candidatos e pesquisa por características. Implementa filas, pilhas e listas encadeadas do zero.

`Python` `Estruturas de Dados`

---

### [Site de Receitas](https://github.com/GuiDobelin/Site_Django)
Site de receitas com Django usando templates parciais reaproveitáveis e configuração por variáveis de ambiente.

`Python` `Django` `HTML` `CSS`
